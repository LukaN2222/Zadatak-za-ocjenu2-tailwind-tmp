Ime projekta:Kafić Zrno

Ovo je stranica o izmišljenom kafiću Zrno. Koristom tailwinda dizajnirao sam kako izlgedaju stranice pomoću različitih komadi poput max-w-6x1 koja nam omogućuje maksimalnu širinu koju ne može prijeći.
Stranice korištene u ovom projektu su:index.html(služi nam kao početna stranica), usluge.html i kontakt.html
